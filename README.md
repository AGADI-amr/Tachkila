# Tachkila – Team Lineup Management

## Project Overview
Tachkila is a web application designed to help football coaches manage their team roster and create a starting lineup using a 4-4-2 formation. It allows users to add, edit, and delete players, assign them to compatible positions on the field, and identify player roles and position status through color coding.

## Skills Learned
- **DOM Manipulation:** Selecting, creating, modifying, and removing HTML elements.
- **Event Handling:** Managing events, event propagation, and event delegation.
- **Form Validation:** Using regular expressions (Regex) to validate user input.
- **JavaScript:** Managing player data and implementing assignment rules.
- **CSS Grid:** Designing a football field with 11 positions in a 4-4-2 formation.
- **Tailwind CSS:** Building a responsive and user-friendly interface.
- **Problem-Solving:** Applying business rules to ensure player-position compatibility and prevent invalid assignments.
